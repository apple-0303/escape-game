# 逃離遊戲 Escape Game

將 2023 年以 C++ 製作的文字逃脫遊戲改編為可在瀏覽器遊玩的像素風 2D 網頁遊戲。

玩家將依序逃離陌生房間、屋子與樹林，透過調查場景、收集物品與閱讀線索，找出正確的密碼與道路。

## 遊玩方式

直接以瀏覽器開啟 `index.html` 即可遊玩；或透過網站連結遊玩。

## 操作說明

- 點擊場景中的物件或門來調查、移動。
- 手機上場景圖比螢幕寬時，可用手指拖曳畫面移動視角。
- 點擊右上角的「背包」可重新查看已收集的物品與線索。

## 遊戲流程

1. **離開房間**：調查床、書桌與保險箱，找出鑰匙。
2. **離開屋子**：探索客廳、廚房、書房與廁所，收集四張撲克牌並解開大門。
3. **走出樹林**：根據環境線索選擇正確道路。

## 專案結構

```text
.
├── index.html      # 遊戲主程式（HTML、CSS、JavaScript）
├── game.cpp        # 原始 C++ 文字遊戲
├── SPEC.md         # 遊戲規格書
└── assets/         # 像素場景圖片
```

## 技術

- HTML
- CSS
- JavaScript

遊戲不需後端或額外套件，可直接部署為靜態網站。

## 改編說明

網頁版保留原始 `game.cpp` 的主要劇情、謎題、物品與隨機傳送機制；日記改為可翻閱的一週紀錄，森林關則加入可主動查看的環境提示，避免純靠嘗試通關。

## 素材

`assets/` 內的像素場景圖依遊戲文本描述製作，供本專案使用。
